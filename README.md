# `biblissima`

> *See [release notes](https://github.com/neelsmith/biblissima/blob/main/releases.md).*


`biblissima` is a Python package for working with data from the 
invaluable portal at [https://portail.biblissima.fr](https://portail.biblissima.fr). Its focus is on illustrated manuscripts documented with IIIF manifests. Its main goals are:

- extract a relevant subset of information from the Biblissima porta and make it available in delimited-text files
- add CTS URN identifiers for all texts
- add CITE2 URN identifiers for manuscript pages
